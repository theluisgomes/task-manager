# Typography — Task Manager Pro

## Font family

**Plus Jakarta Sans** (Google Fonts) — friendly, modern SaaS.

## Scale

| Role | Size | Weight | Usage |
|------|------|--------|-------|
| heading-xl | 28px (1.75rem) | 600 | Page title (h1), once per screen |
| heading-m | 20px (1.25rem) | 600 | Section headings (h2) |
| body | 16px | 400 | Default body text |
| body-small | 14px (text-sm) | 400 | Metadata, captions |
| caption | 12px (text-xs) | 500 | Uppercase stat labels |

## Implementation

Defined in `client/src/index.css` `@layer base`.
